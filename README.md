# NSPCA Website - WEDE5020 Part 3

## 1. Project Overview

This project is a continuation of the WEDE5020 website development project, It focuses on the National Council of SPCAs (NSPCA) and animal welfare in South Africa.

The website provides information about the NSPCA, its work, services, donations, volunteering, news, enquiries and contact details.

## 2. Project Objectives

-   Provide clear information about animal welfare

- Create a website that is easy to navigate

- Support desktop and mobile screen sizes

-  Improve website functionality using JavaScript

- Apply search engine optimisation (SEO) principles

-   Provide enquiry and contact forms with validation

-  Encourage users to support animal welfare

## 3. Website Pages

- `index.html` - Homepage
- `about.html` - Information about the NSPCA
- `services.html` - Animal welfare information and services
- `enquiry.html` - Enquiry form
- `donate.html` - Donation information
- `volunteer.html` - Volunteering information
- `news.html` - News and updates
- `contact.html` - Contact details and contact form

## 4. The Technologies that were Used

-   HTML5 for website structure
- CSS3 for styling and responsive design
-  JavaScript for interactive features and form validation
-    GitHub for version control and project hosting

## 5. The Responsive Design

The website is designed to support different screen sizes, including desktop and mobile devices. CSS layout techniques and responsive styling are used to improve usability

## 6. The Search Engine Optimisation (SEO)

SEO improvements include page-specific titles, meta descriptions, relevant keywords, structured headings, descriptive image and alternative text, internal links, a sitemap and a robots.txt file
